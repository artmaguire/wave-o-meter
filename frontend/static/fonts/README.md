# Fonts

Place the licensed **Linear Sans** woff2 files here:
- `LinearSans-Regular.woff2` (400)
- `LinearSans-Medium.woff2` (500)
- `LinearSans-Semibold.woff2` (600)

They are referenced via @font-face in `src/app.css`. Until present, the UI falls
back to the system sans-serif stack (system-ui, Segoe UI, Roboto…).

Note: Linear Sans is a commercial typeface — ensure your license permits
self-hosted web use. Open alternatives with a similar feel: Inter, Geist,
Hanken Grotesk.
